auto-rtt-viewer / 설치

설치

Python·SEGGER J-Link 설치 후 .venv 1회 설정만 하면, VSCode 터미널에서 auto-rtt-viewer 명령 한 줄로 동작합니다. 이 페이지는 최초 1회 설정만 다룹니다.

Tip
한 번 설정해두면 이후부터는 "VSCode로 폴더 열기 → 터미널에서 auto-rtt-viewer 치기" 두 단계로 끝입니다. 매번 하는 실행은 사용법에서 다룹니다.

1. 준비물

항목설명
Windows 10 / 11—
Python 3.10 이상PowerShell에서 python --version으로 확인
VSCode + Python 확장VSCode 설치 후 확장 탭에서 Microsoft의 "Python" 설치
SEGGER J-Link Software PackSEGGER 공식 사이트에서 설치. JLinkARM.dll이 자동으로 PATH에 등록됨
J-Link 프로브USB로 PC에 연결
타겟 보드SWD/JTAG 결선 + 펌웨어에 RTT 초기화 포함
Note
Sound1(E8300)은 부트로더에서 SEGGER_RTT를 초기화하므로 펌웨어 쪽 준비는 따로 필요 없습니다.

2. 최초 1회 설정

Tip
프로젝트 폴더에 이미 .venv가 있다면 2.3을 건너뛰고 2.1 → 2.2 → 2.4만 하면 됩니다.

2.1 VSCode로 프로젝트 폴더 열기

  • VSCode 실행 → File → Open Folder → 프로젝트 폴더 선택 (소스를 받은 위치).
  • "Do you trust the authors..." 창이 뜨면 Yes, I trust the authors 클릭.
  • 터미널 열기: 메뉴 Terminal → New Terminal 또는 Ctrl+Shift+`.
Important
이렇게 열면 터미널의 현재 경로가 자동으로 프로젝트 폴더가 됩니다. 이 "경로가 프로젝트 폴더"라는 조건이 이후 모든 단계의 전제입니다. VSCode 없이 PowerShell을 직접 열었다면 먼저 cd로 프로젝트 폴더로 이동하세요.

2.2 PowerShell 실행 정책 허용

PowerShell은 기본적으로 스크립트 실행을 막아둡니다. 나중에 Activate.ps1을 쓸 때 이런 에러가 나면:

이 시스템에서 스크립트를 실행할 수 없으므로 ... Activate.ps1 파일을 로드할 수 없습니다.

터미널에서 한 번만 다음을 실행합니다 (이 PC, 이 계정 전체에 영구 적용됨):

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Note
RemoteSigned는 내 PC에서 만든 스크립트는 그대로 실행하고, 인터넷에서 다운로드한 스크립트만 디지털 서명을 요구하는 정책입니다. 관리자 권한이 필요 없습니다.

2.3 가상환경 만들고 패키지 설치

(프로젝트 폴더에 .venv가 이미 있다면 건너뛰세요.)

터미널에서 순서대로:

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
Warning
마지막 줄에서 따옴표 안의 점 위치 주의: ".[dev]" (점이 [ 앞). "[.dev]"가 아닙니다.
  • . = "현재 폴더의 프로젝트"
  • [dev] = "개발용 추가 패키지(pytest 등)도 같이"

설치가 끝나면 터미널에서 auto-rtt-viewer라고 쳤을 때 이 CLI가 실행됩니다. (python -m auto_rtt_viewer도 같은 동작을 하지만, 짧은 쪽 하나만 기억하면 충분합니다.)

2.4 VSCode가 venv를 자동으로 쓰게 지정

이 설정을 한 번 해두면 앞으로 VSCode 터미널을 열 때마다 .venv가 자동 활성화됩니다. 매번 Activate.ps1을 칠 필요가 없어집니다.

  1. Ctrl+Shift+P → 검색창에 Python: Select Interpreter 입력 후 선택.
  2. 목록에서 Python 3.xx.x ('.venv': venv) 선택 (경로가 .\.venv\Scripts\python.exe인 항목).
  3. 터미널을 닫고(휴지통 아이콘) 새 터미널을 엽니다(Ctrl+Shift+`).
  4. 프롬프트 앞에 (.venv)가 표시되면 성공.

예시:

(.venv) PS E:\path\to\auto-rtt-viewer>

3. 설치 확인

다음 두 명령으로 설치가 정상인지 확인합니다.

auto-rtt-viewer --version
auto-rtt-viewer --help
  • --version이 버전 문자열을 출력 → CLI 엔트리포인트 정상.
  • --help가 모든 옵션 (--profile/--device/--interface/--speed/--serial/--logfile/--no-stdout/--telnet-port/--no-telnet/--no-stdin/--timestamp)을 표시 → argparse 정상.

4. 한글 인코딩 사전 처리 (권장)

PowerShell의 기본 문자 인코딩이 cp949라서 CLI의 한글 상태 메시지가 깨질 수 있습니다. 새 터미널마다 다음 한 줄로 UTF-8 전환 가능합니다:

chcp 65001

매번 치기 귀찮다면 VSCode의 settings.json (Ctrl+Shift+P → "Preferences: Open User Settings (JSON)")에 다음을 추가하면 모든 새 PowerShell 터미널이 자동으로 UTF-8로 열립니다:

"terminal.integrated.profiles.windows": {
  "PowerShell (UTF-8)": {
    "source": "PowerShell",
    "args": ["-NoExit", "-Command", "chcp 65001 | Out-Null"]
  }
},
"terminal.integrated.defaultProfile.windows": "PowerShell (UTF-8)"
