NofM 알고리즘

Sound1 CFX의 N-of-M 자극 전략 구현 정리. 32 주파수 대역 중 에너지 상위 N(=16)개만 선택하여 자극 → 공간 분산 → 1 ms 한도 내 strided FIFO 기록. stimulationStrategy.c 의 6 신규 함수 중심.

핵심 아이디어 5종

① Packed Score
진폭과 주파수 인덱스를 단일 32-bit 정수에 패킹:
score = (amp << 5) | (31 - idx)
동률 시 저주파(작은 idx) 우선.
② Bitmask Sort
16 선택된 packed score의 하위 5비트(& 0x1F)에서 원본 인덱스 복원 → 32-bit 비트마스크 set → 오름차순 순회로 자동 정렬.
③ Stride Interleaving
정렬된 16 대역을 half_ch = 8 단위로 분할 후 [A[0], A[8], A[1], A[9], ...] 식 교차 → 인접 전극 연속 자극 회피.
④ Loop Peeling
이전 프레임 last 자극 전극과 현재 시퀀스 first/last 절대거리 비교 → forward(0) / reverse(N-1) 시작점 선택. modulo 회피.
⑤ Strided Overwrite
FIFO 전체를 NOP으로 일괄 채우고 stride = g_pcmFrameNum_per_channel 간격으로 자극 패킷 덮어쓰기.

2단계 Phase 사이클

g_NofM_Phase (0/1) 로 신호처리 부하 분산. Phase 0 = 풀 파이프라인, Phase 1 = 신호처리 생략 (전송 잔여만).

매 사이클 끝에 stimulationStrategy_NofM_PCM_Write()가 호출되어 FIFO 기록. Case B (펄스 N > 1 ms 한도)일 때 addr_transferred_index가 보존되어 다음 사이클(Phase 1)에서 잔여 펄스 이어 전송.
