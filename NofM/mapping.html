4축 인덱스 공간

NofM·CIS 자극 데이터는 4개의 독립 인덱스 공간을 거쳐 PCM 패킷이 된다. 각 변환마다 별도 룩업 테이블 필요.

왜 이렇게 생겼는가
ISD 하드웨어의 전극 물리 배치(와우 기저↔첨단) 순서가 ISD 레지스터 주소 순서와 다르기 때문. 환자용 맵은 기저→첨단 자연 순서로 작성되고, CFX는 마지막 PCM 패킷 단계에서만 ISD 레지스터 주소 순서로 재배치.
CFX·CM3 양쪽 중복
동일 배열이 두 곳에 존재:
  • CFX: src/1__cfx/signalProcessing/stimulationStrategy.c:14
  • CM3: src/2__cm3/.../isd_interface_stimulationParaSetting.c 의 electrodeMap[]
두 곳 값이 엇갈리면 즉시 자극 좌표가 뒤바뀜. 누구든 한 쪽만 수정하면 환자에게 엉뚱한 전극이 자극됨. 단일 헤더로 추출하는 게 권장.

NofM Packet 단계 — 비트 패킹 구현

freqBandOrder = g_NofM_notAdjacent_BandIndex[pcmIdx];                                       // notAdjacent 순서대로 band
electrodIndex = addr_MapProgramData_StimulusChannelAssignedElectrodIndex[freqBandOrder] - 1; // band → logical (0-based)
electrodeMap  = addr_electrodeMap[electrodIndex] << electrodIndexPositionAtPCM_Mold;          // logical → physical, bit 10 위치
stimulusLevel = g_pcm_amplitude_level[freqBandOrder] << stimulationPositionAtPCM_Mold;        // amp → bit 2 위치
addr_stimulationTempBuff[pcmOut++] = electrodeMap | stimulusLevel | g_pcm_stimulation_packet_header;

Step 1 — FFT bin → 밴드 대표값 (find_freq_rep_value)

FrequencyAnalysis.c:45. 256 bin 중 같은 그룹(pass_bin_index[bin])에 속한 bin의 최대 magnitude를 그룹의 대표값으로.

for (bin = 0; bin < 256; bin++) {
    group = g_pass_bin_index[bin];
    mag   = VMAG_OUTPUT[bin];
    if (group >= 0) {
        g_freq_rep_values[group] = max(prev, mag);
    }
}

// 게인 보정 (FFT_SIZE/32 = 2^4)
for (i = 0; i < 32; i++) {
    g_freq_rep_values_scaled[i] = g_freq_rep_values[i] >> 4;
}

Step 2 — Greenwood 분할 + pass_bin_index

0~8 kHz를 Greenwood 함수로 N 밴드로 비선형 분할. 저주파에 bin 많고 고주파는 듬성. pass_bin_index[]는 CM3가 맵 로드 시 FS 메모리에 작성, CFX가 read_FFT_PassBin_index()로 복사.

Step 3 — Logarithmic Mapping

nonlinearMapping.c의 logarithmMapping(). T-level/C-level/xMin/xMax 기준으로 진폭(0~255)으로 매핑. Q16.8 산술 + branchless clamp.
