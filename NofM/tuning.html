튜닝 파라미터

NofM 본체 통합 이후 실 동작 검증 중 적용한 5 변경. 영구 3건 + 임시 2건.

변경 요약

#위치분류변경
①CFX driver_PCM_liveStimulation.c영구connectionCheck 직후 NopStandby → NopBacktel 강제 (2 슬롯)
②CFX stimulationStrategy.c영구NofM stride 정책 명시 (g_pcmFrameNum_per_channel 사용, backup 가지 보존)
③CFX stimulationStrategy.c임시NofM 진입 직후 amplitude 16 인덱스 결정론적 벡터 강제 (검증용)
④CM3 ci_map.c임시Map3 (CI_MAP_NUM_3_INDEX) stimulationStrategy = nOFm 강제
⑤CM3 stimulationParaCal.c영구NofM 가용 조건 가드 (numFrequencyBand ≥ 16) + frameNumPerOneChannel=3 강제

① 백텔 강제 (frame_3_perChannel)

src/1__cfx/internalDevice/driver_PCM_liveStimulation.c, L154~165 부근.

+   /* IMPORTANT : 펄스 폭 설정과 관계 없이
+    * pcm_Mold_connectionCheck 출력 후 바로 pcm_Mold_NopBacktel을 적용함으로써
+    * 백텔 수신 실패의 경우가 없도록 한다. */

    *((int _XMEM *) HEAR_ADDR_FIFO_PCM_WRITING)     = pcm_Mold_connectionCheck;
-   *((int _XMEM*) HEAR_ADDR_FIFO_PCM_WRITING - 1) = pcm_Mold_NopStandby;
-   *((int _XMEM*) HEAR_ADDR_FIFO_PCM_WRITING - 2) = pcm_Mold_NopStandby;
+   *((int _XMEM *) HEAR_ADDR_FIFO_PCM_WRITING - 1) = pcm_Mold_NopBacktel;
+   *((int _XMEM *) HEAR_ADDR_FIFO_PCM_WRITING - 2) = pcm_Mold_NopBacktel;
이유
NofM 시 프레임 수가 3으로 고정되는데, 펄스 폭 설정에 따라 FPGA COLA 프로토콜 전송 시간이 1 프레임으로 끝날 가능성 존재. 그 경우 pcm_Mold_connectionCheck 직후 슬롯이 NopStandby면 내부기 Backtel 송신을 수신 못 해 에러 발생. NopBacktel로 강제하여 항상 수신 준비 상태 유지.

Trade-off: 전력 소비 소폭 증가 (Backtel 회로 가동 시간 2 프레임 추가). 사용자 판단 = "2 프레임 정도는 큰 의미 없음".

② stride 정책 명시 (NofM_PCM_Write)

    int _XMEM *p_pcmFIFO = (int _XMEM *) HEAR_ADDR_FIFO_PCM_WRITING;

이유
초기에 NofM 시 stride를 3으로 직접 고정하려 했으나, 단일 함수 내 하드코딩보다 CM3 측에서 공유메모리 g_pcmFrameNum_per_channel에 3을 쓰는 방향으로 전환. CFX 측은 공유메모리 값을 그대로 읽음 (#if 1 가지). #else 가지는 backup 의도 보존 (재활용 가능성).

결과 흐름: CM3 stimulationParaCal.c (⑤)에서 NofM 시 frameNumPerOneChannel = 3 → 공유메모리 → CFX가 stride = 3으로 사용.

로직
NofM 프레임 수 3 고정 → 1 ms 최대 채널 수 = 8 (=24/3). NofM의 의미(다중 채널 동시 자극)가 살아 있으려면 가용 채널 수 ≥ 16이어야 함.
  • 16 미만: ci_printe로 에러 출력, 자극 파라미터 자동 보정 안 함 (사용자가 맵 재구성 유도)
  • 16 이상: frameNumPerOneChannel = 3, transferableChannelNum = 8 강제

연계: 본 함수가 공유메모리에 g_pcmFrameNum_per_channel = 3을 쓰는 경로. ② CFX stride와 양방향 핸드셰이크 완성.

영향 범위

영역동작 변경

영향 받지 않는 영역

  • CIS 자극 모드: stimulationStrategy_CIS() 무변경
  • NofM 본체 알고리즘 (Peak_Pick·Interleaving·Packet): 다니엘 작성·검증 완료, 본 task 미변경
  • Map1·Map2·Map4: stimulationStrategy = 1 (CIS) 유지
  • Backtel 인입 회로 동작 (Enable_backtelCircuit(), Disable_backtelCircuit()): 무변경
