Peak Pick · Interleaving · Packet

1. Peak Pick — 32 → 16 선택 (Packed Score + Bitmask Sort)

주파수 대역 32개 중 진폭 상위 16개를 선택. 진폭 동률 시 저주파 우선. stimulationStrategy_NofM_Peak_Pick(), stimulationStrategy.c:116~232.

Step 1 — Packed Score 사전 계산

int packed_scores[df_MaxNumOfElectrode];   // 32 슬롯

for (i = 0; i < df_MaxNumOfElectrode; i++) {
    packed_scores[i] = (g_pcm_amplitude_level[i] << 5) | (31 - i);
}

각 전극의 진폭(8-bit)을 5비트 좌측 시프트 → 상위 비트, 하위 5비트에 31 - i(인덱스 뒤집어 저장).

핵심 트릭
진폭 동률 시 저주파(작은 i)가 더 큰 31 - i를 가져 packed score가 큼 → 정렬 시 저주파 우선.
예: Low(idx 2, amp 10) = (10<<5) | 29 = 349 > High(idx 6, amp 10) = (10<<5) | 25 = 345 → 고주파가 더 약한 peak로 평가됨.
정렬 단계와 tiebreak가 한 번에 패킹 — 별도 비교 로직 불필요.

Step 2 — 초기 버킷 채움 + 최소값 탐색

// 전극 0~15 packed score 그대로 버킷
for (i = 0; i < df_MaxNum_NofM; i++) {
    top_packed[i] = packed_scores[i];
}

register int min_packed = top_packed[0];
register int min_idx_in_bucket = 0;

for (i = 1; i < df_MaxNum_NofM; i++) {
    if (top_packed[i] < min_packed) {
        min_packed = top_packed[i];
        min_idx_in_bucket = i;
    }
}

Step 3 — Brute-force Bucket Swap (idx 16~31 스캔)

for (i = df_MaxNum_NofM; i < df_MaxNumOfElectrode; i++) {   // 16..31
    if (packed_scores[i] > min_packed) {
        top_packed[min_idx_in_bucket] = packed_scores[i];   // 약한 peak 교체

        // 새 약한 peak 재탐색 (O(N))
        min_packed = top_packed[0];
        min_idx_in_bucket = 0;
        for (t = 1; t < df_MaxNum_NofM; t++) {
            if (top_packed[t] < min_packed) {
                min_packed = top_packed[t];
                min_idx_in_bucket = t;
            }
        }
    }
}

워스트 케이스 시간 복잡도 O(M·N) = O(32·16) = 512 비교. CFX 자극 사이클 (2 ms × Phase 0) 안에 충분.

Step 4 — Bitmask Sort (Frequency 오름차순 자동 정렬)

register unsigned long present_mask = 0;

// 하위 5비트 (& 0x1F) 마스킹으로 원본 인덱스 복원 → 비트 set
for (i = 0; i < df_MaxNum_NofM; i++) {
    register int original_idx = 31 - (top_packed[i] & 0x1F);
    present_mask |= (1UL << original_idx);
}

// 비트마스크를 0..31 순회하며 set 비트만 추출
register int presentOut = 0;
for (b = 0; b < df_MaxNumOfElectrode; b++) {
    if (present_mask & (1UL << b)) {
        g_NofM_adjacent_BandIndex[presentOut++] = b;
    }
}
왜 비트마스크
16개 정렬을 O(N²) 비교 정렬 없이 O(M)=O(32) 비트 스캔으로 처리. 동시에 sparse → dense 변환 (32 전극 중 16 선택의 dense 인덱스 추출). 원본 알고리즘의 int present[32] 배열 대비 RAM 32× 절약.

출력: g_NofM_adjacent_BandIndex[0..15] = 에너지 상위 16 대역의 인덱스, 주파수 오름차순 정렬.

2. Interleaving — ID-Sorted Stride 공간 분산

정렬된 adjacent_BandIndex[0..15]를 절반 분할([0..7], [8..15]) 후 짝/홀 인덱스에 교차 배치. stimulationStrategy_NofM_Interleaving(), stimulationStrategy.c:234~269.

void stimulationStrategy_NofM_Interleaving(void) {
    int half_ch = df_MaxNum_NofM / 2;    // 8

    for (i = 0; i < half_ch; i++) {
        g_NofM_notAdjacent_BandIndex[i * 2]     = g_NofM_adjacent_BandIndex[i];
        g_NofM_notAdjacent_BandIndex[i * 2 + 1] = g_NofM_adjacent_BandIndex[i + half_ch];
    }

    if (df_MaxNum_NofM % 2 != 0) {    // 16 → false (홀수 N 대비)
        g_NofM_notAdjacent_BandIndex[df_MaxNum_NofM - 1] = g_NofM_adjacent_BandIndex[df_MaxNum_NofM - 1];
    }
}

매핑 결과

i짝수 idx (i*2)값홀수 idx (i*2+1)값
00adj[0]1adj[8]
12adj[1]3adj[9]
24adj[2]5adj[10]
...............

결과: notAdjacent_BandIndex = [adj[0], adj[8], adj[1], adj[9], adj[2], adj[10], ..., adj[7], adj[15]]

효과
연속 자극되는 두 전극의 idx 차이가 약 8 (half_ch) → 전기적 crosstalk(인접 전극 간섭) 감소. 단순 순차 자극 [0,1,2,...,15] 대비 공간 간격 8배.

3. Packet — 거리 기반 시작점 + Loop Peeling + Mute

16 PCM 자극 패킷 생성. 이전 프레임 last 자극 전극과 현재 시퀀스 first/last 거리 비교로 시작점 결정. stimulationStrategy_NofM_Packet(), stimulationStrategy.c:271~346.

Step 1 — 시작점 결정 (first/last 2개만 비교, O(1))

int NofM_maxIndex   = df_MaxNum_NofM - 1;   // 15
int first_electrode = g_NofM_notAdjacent_BandIndex[0];
int last_electrode  = g_NofM_notAdjacent_BandIndex[NofM_maxIndex];
int prev_last_stim  = g_NofM_LastStimulus_BandIndex;

int dist_to_first = abs(first_electrode - prev_last_stim);
int dist_to_last  = abs(last_electrode  - prev_last_stim);

int start_idx = (dist_to_last > dist_to_first) ? NofM_maxIndex : 0;
원본 알고리즘 대비 최적화
원본은 16 슬롯 전부와 거리 비교 → bestIndex 탐색 (O(N)). 다니엘 구현은 first/last 2개만 비교 → O(1). 정당화 근거: notAdjacent 정렬이 stride 패턴이라 first/last 만 후보로 유효 (intermediate은 항상 first/last보다 가깝거나 같음).

Step 2 — 다음 프레임용 LastStimulus 사전 업데이트

if (start_idx == 0) {
    g_NofM_LastStimulus_BandIndex = last_electrode;             // forward → 마지막 = last
} else {
    g_NofM_LastStimulus_BandIndex = g_NofM_notAdjacent_BandIndex[df_MaxNum_NofM - 2];  // reverse → 마지막 = N-2
}

왜 N-2 (reverse): reverse 시퀀스는 [N-1, 0, 1, 2, ..., N-2] 순서로 자극 → 마지막 자극 슬롯이 N-2.

Step 3 — Sequence Generation with Loop Peeling

Loop Peeling = 첫(또는 끝) 반복 1회를 루프 밖으로 빼고 나머지를 단순 루프로 — modulo/조건 분기 제거 최적화.

int pcmOut = 0;

// Peeled: reverse 시퀀스의 첫 자극 (= N-1 슬롯) 단독 처리
if (start_idx == NofM_maxIndex) {
    freqBandOrder = g_NofM_notAdjacent_BandIndex[NofM_maxIndex];
    electrodIndex = addr_MapProgramData_StimulusChannelAssignedElectrodIndex[freqBandOrder] - 1;
    electrodeMap  = addr_electrodeMap[electrodIndex] << electrodIndexPositionAtPCM_Mold;

    if (mute_enabled && g_pcm_amplitude_level[freqBandOrder] == 0) {
        addr_stimulationTempBuff[pcmOut++] = ISD_registerAddr_forwardPath_check_Data;
    } else {
        stimulusLevel = g_pcm_amplitude_level[freqBandOrder] << stimulationPositionAtPCM_Mold;
        addr_stimulationTempBuff[pcmOut++] = (electrodeMap | stimulusLevel | g_pcm_stimulation_packet_header);
    }
}

// 나머지: 0..(loop_end-1) 순차 처리
int loop_end = (start_idx == NofM_maxIndex) ? NofM_maxIndex : df_MaxNum_NofM;

for (pcmIdx = 0; pcmIdx < loop_end; pcmIdx++) {
    // (같은 패킷 생성 로직)
}
