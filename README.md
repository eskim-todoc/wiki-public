# wiki-public

eskim-todoc 개인 wiki의 **HTML 공개 후보 mirror**입니다.
원본은 private 저장소 `eskim-todoc/wiki`이며, 본 저장소는 GitHub Pages 호스팅 전용입니다.

## 사이트

- [auto-rtt-viewer](https://eskim-todoc.github.io/wiki-public/auto-rtt-viewer/) — J-Link RTT Auto Connect CLI 정리 문서

## 운영 원칙

- 본 repo는 **HTML 산출물 mirror**만 포함합니다. 원본 마크다운·작업 산출물은 private repo에서 관리됩니다.
- 갱신은 private wiki의 1차/2차 가공이 완료된 콘텐츠를 mirror로 동기화하는 방식입니다.
- 공개 검수 완료된 콘텐츠만 본 repo에 반영됩니다.
